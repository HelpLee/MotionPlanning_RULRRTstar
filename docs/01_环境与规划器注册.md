# 1. Environment and MoveIt planner registration / 环境与 MoveIt 规划器注册

本页的命令在 **Ubuntu 18.04 + ROS Melodic + MoveIt 1** 终端执行。把本仓库克隆到任意目录，下文用 `REPO` 表示其绝对路径。实验脚本使用 Melodic 的 Python 2 `moveit_commander`。

Run these commands on **Ubuntu 18.04 with ROS Melodic and MoveIt 1**. Clone this repository to any directory and set `REPO` to its absolute path. The experiment runner uses Melodic's Python 2 `moveit_commander`.

## 1.1 Install ROS and build tools / 安装 ROS 与构建工具

先按 [ROS Melodic 的 Ubuntu 安装文档](https://wiki.ros.org/melodic/Installation/Ubuntu) 配置 ROS 软件源并安装 `ros-melodic-desktop-full`。再安装常用构建工具：

Follow the [ROS Melodic Ubuntu installation guide](https://wiki.ros.org/melodic/Installation/Ubuntu) to configure the ROS package source and install `ros-melodic-desktop-full`. Then install the build tools:

```bash
sudo apt update
sudo apt install git build-essential cmake python-catkin-tools python-rosdep python-numpy
sudo rosdep init  # once per machine / 每台机器只执行一次
rosdep update
source /opt/ros/melodic/setup.bash
```

已经初始化过 `rosdep` 时，跳过 `sudo rosdep init`。后面的 `rosdep install` 会根据所检出包的 `package.xml` 安装其它系统依赖。

Skip `sudo rosdep init` if it has already been run. The later `rosdep install` resolves system dependencies declared by the checked-out packages.

## 1.2 Check out pinned third-party sources / 检出固定版本的第三方源码

```bash
export REPO="$HOME/MotionPlanning_RULRRTstar"  # replace with the actual absolute path / 改为实际绝对路径
mkdir -p "$HOME/ws_moveit/src"
cd "$HOME/ws_moveit"
catkin init
python3 "$REPO/tools/checkout_sources.py" "$HOME/ws_moveit/src"
python3 "$REPO/tools/checkout_sources.py" "$HOME/ws_moveit/src" --check
```

`tools/source-revisions.json` 锁定 MoveIt、`universal_robot` 和相关依赖的 commit。独立的 OMPL 库使用 ROS 环境提供的版本；自定义 C++ 会编入 MoveIt 的 OMPL 接口。若要阅读 OMPL 1.4.2 上游基底，可在工作区外单独检出 `ompl/ompl` 的 commit `c7fc1452bb77d5dee417e25a6ce2b2c5feb6fd5c`，无需把这个仓库放进 catkin `src/`。

`tools/source-revisions.json` pins the MoveIt, `universal_robot`, and supporting commits. The standalone OMPL library comes from the ROS environment; the custom C++ is compiled into MoveIt's OMPL interface. For upstream OMPL 1.4.2 reference code, check out `ompl/ompl` commit `c7fc1452bb77d5dee417e25a6ce2b2c5feb6fd5c` outside the catkin workspace.

## 1.3 Integrate the planners / 接入规划器

The integration touches the following files. Review the mapping before running the registration script. / 接线位置如下；运行注册脚本前先确认这些文件的作用。

| Location / 位置 | Addition / 添加内容 | Purpose / 作用 |
| --- | --- | --- |
| `planner/src/ompl/geometric/planners/rrt/` | `RULRRTstar.h/.cpp`, `BaseRRTstar.h/.cpp` | Implement both OMPL planners / 实现两种规划器 |
| `planner/src/ompl/base/objectives/` | Two objective header/implementation pairs / 两套优化目标源码 | Define planning costs / 定义规划代价 |
| MoveIt `planning_context_manager.cpp` | Headers and allocator IDs `geometric::RULRRTstar`, `geometric::BaseRRTstar` / 头文件与 allocator ID | Instantiate planners by ID / 按 ID 创建规划器 |
| MoveIt `ompl_interface/CMakeLists.txt` and package manifests / CMake 与包清单 | Four `.cpp` files, include path, `std_msgs` / 四个实现文件、头文件路径及依赖 | Compile into `moveit_ompl_interface` / 编入接口库 |
| UR5 `ompl_planning.yaml` | Both IDs, `range=0.05`, `goal_bias=0.05`, `manipulator` membership / 两种 ID 及参数 | Expose planners to `set_planner_id()` / 供实验脚本选择 |

The essential addition to MoveIt's `planning_context_manager.cpp` is shown below. / `planning_context_manager.cpp` 中的关键接线形式如下：

```cpp
#include <ompl/geometric/planners/rrt/BaseRRTstar.h>
#include <ompl/geometric/planners/rrt/RULRRTstar.h>
// Place beside the existing RRTstar allocator / 放在现有 RRTstar allocator 附近
registerPlannerAllocator("geometric::BaseRRTstar",
    std::bind(&allocatePlanner<og::BaseRRTstar>, std::placeholders::_1,
              std::placeholders::_2, std::placeholders::_3));
registerPlannerAllocator("geometric::RULRRTstar",
    std::bind(&allocatePlanner<og::RULRRTstar>, std::placeholders::_1,
              std::placeholders::_2, std::placeholders::_3));
```

Add the four `.cpp` files and the `planner/src` include path to `moveit_ompl_interface`. Add `std_msgs` to the parent catkin component list and `package.xml`. The following CMake is illustrative: replace `$REPO` with an absolute path, or let the registration script write it. / 同时修改接口库的 CMake、上级 catkin 组件和包依赖；以下示意中的 `$REPO` 须替换为绝对路径，自动脚本会完成替换。

```cmake
target_sources(moveit_ompl_interface PRIVATE
  "$REPO/planner/src/ompl/geometric/planners/rrt/src/BaseRRTstar.cpp"
  "$REPO/planner/src/ompl/geometric/planners/rrt/src/RULRRTstar.cpp"
  "$REPO/planner/src/ompl/base/objectives/src/BasePathLengthOptimizationObjective.cpp"
  "$REPO/planner/src/ompl/base/objectives/src/RULAwareOptimizationObjective.cpp")
target_include_directories(moveit_ompl_interface PRIVATE "$REPO/planner/src")
```

In YAML, map `BaseRRTstar` and `RULRRTstar` to their `geometric::` types and list both under `manipulator.planner_configs`. The repository supplies the finished configuration at `ros/ur5_moveit_config/config/ompl_planning.yaml`. / YAML 中的两个键须映射至相应类型，并同时加入 `manipulator.planner_configs`；仓库已提供配置成品。

Run the registration script / 运行自动接线脚本：

```bash
python3 "$REPO/tools/register_moveit.py" "$HOME/ws_moveit/src/moveit"
```

脚本会先检查预期文件和代码锚点，再写 MoveIt 的四个文件；重复运行会识别已注册状态。它在 CMake 中使用仓库的绝对路径，所以移动本仓库后，应在干净的 MoveIt checkout 上重新运行。

The script validates its anchors before editing four MoveIt files and detects a completed registration on subsequent runs. It writes an absolute source path into CMake. If the repository moves, rerun it on a clean MoveIt checkout.

这里的“注册到 OMPL”分两层：类继承 OMPL 规划器 API，MoveIt 的 OMPL 接口负责按规划器 ID 实例化它们。这套 C++ 还发布 ROS `/joint_usage`、`/joint_loss` 话题，因此编译目标是 `moveit_ompl_interface`，不是纯 `libompl`。

Integration has two layers: the classes implement OMPL planner APIs, while MoveIt's OMPL interface instantiates them by ID. Because these implementations publish ROS topics, their build target is `moveit_ompl_interface`, not the standalone `libompl`.

## 1.4 Install UR5 configuration and build / 安装 UR5 配置并构建

`universal_robot` 原包的默认 `ur5_moveit_config` 不含本项目两个 ID。用仓库里的配置覆盖该包：

The default `ur5_moveit_config` in `universal_robot` does not contain the two custom IDs. Overlay it with the configuration in this repository:

```bash
cp -a "$REPO/ros/ur5_moveit_config/." \
  "$HOME/ws_moveit/src/universal_robot/ur5_moveit_config/"
cd "$HOME/ws_moveit"
rosdep install -y --from-paths src --ignore-src --rosdistro melodic
catkin config --extend /opt/ros/melodic \
  --cmake-args -DCMAKE_BUILD_TYPE=Release \
  -Dompl_DIR=/opt/ros/melodic/share/ompl/cmake
catkin build moveit_planners_ompl ur5_moveit_config
source devel/setup.bash
```

如果 `rosdep` 指出某个 ROS 包未安装，按它显示的包名安装相应 `ros-melodic-*` 包后重试。UR5 配置引用 `ur_description`、`trac_ik_kinematics_plugin` 等依赖；`universal_robot` 提供前者的源码，后者由 ROS 包安装。

If `rosdep` reports an unavailable ROS dependency, install the corresponding `ros-melodic-*` package and retry. `universal_robot` supplies `ur_description`; the UR5 configuration also uses packages such as `trac_ik_kinematics_plugin`.

## 1.5 Verify registration / 检查注册结果

```bash
rg 'geometric::(RULRRTstar|BaseRRTstar)' \
  "$HOME/ws_moveit/src/moveit/moveit_planners/ompl/ompl_interface/src/planning_context_manager.cpp"
rg 'RULRRTstar|BaseRRTstar' \
  "$HOME/ws_moveit/src/universal_robot/ur5_moveit_config/config/ompl_planning.yaml"
rg 'RULRRTstar.cpp|BaseRRTstar.cpp' \
  "$HOME/ws_moveit/src/moveit/moveit_planners/ompl/ompl_interface/CMakeLists.txt"
```

Ubuntu 若未装 `rg`，上面三条可把 `rg` 换成 `grep -E`。再运行 `find "$HOME/ws_moveit/build" -name link.txt -path '*ompl_interface*'` 找到链接命令，确认其中含四个自定义对象，且 OMPL 库来自本次配置的同一安装前缀。完成后进入 [实验运行](02_实验运行与结果.md)。

Use `grep -E` in place of `rg` if ripgrep is unavailable. Locate the link command with `find "$HOME/ws_moveit/build" -name link.txt -path '*ompl_interface*'`; inspect it for all four custom objects and the selected OMPL library. Continue with [experiment execution](02_实验运行与结果.md).
